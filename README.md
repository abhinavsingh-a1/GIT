1. Open terminal in the repository directory <br>
   => cd /path/to/your/repository<br>

3. Check current status<br>
   => git status<br>

5. Add files to Git staging area<br>
   => git add .<br><br>

7. Verify staged files<br>
   => git status<br>

9. Create a commit<br>
    => git commit -m "Added new files"<br>

11. Check which branch you are on<br>
    => git branch or git branch --show-current<br>

13. Pull latest changes first (recommended)<br>
    => git pull origin main<br>

15. Push changes<br>
    => git push origin main<br><br>
